# Imágenes de productos

La versión fuente disponible no contenía archivos de fotografía de producto ni etiquetas `<img>`; por eso no se inventaron fotografías oficiales. Esta carpeta queda preparada para agregar fotos propias o autorizadas, con nombres relacionados al SKU, por ejemplo `P001.jpg`.

Para que las fotografías aparezcan en el catálogo, la aplicación debe incluir referencias a estos archivos desde `js/app.js` y mostrar un elemento `<img>` en las tarjetas de producto.
