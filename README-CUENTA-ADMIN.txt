PASOS
1. Extrae todo el ZIP en una carpeta nueva.
2. Abre index.html desde esa carpeta.
3. Inicia sesión con cualquiera de las cuentas indicadas.

El archivo js/app.js crea o repara las tres cuentas demo en localStorage al iniciar. Si abriste una versión anterior, usa esta carpeta nueva.
Estas son credenciales de demostración local, no cuentas de un servidor externo.
